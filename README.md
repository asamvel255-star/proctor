## О проекте

**Qostanai Proctor** — desktop-приложение для локального контроля прохождения онлайн-тестов.

Система одновременно анализирует изображение с веб-камеры и состояние компьютера, фиксируя потенциальные нарушения. Вместо бинарного «списывает / не списывает» приложение рассчитывает **вероятность списывания** на основе нескольких независимых факторов.

Проект работает локально: события сохраняются в папку сеанса, а итоговый отчёт формируется после завершения проверки.

### Что контролируется

- смартфон в кадре;
- смартфон, поднятый к уровню лица;
- закрытая или перекрытая камера;
- отсутствие лица в кадре;
- второй человек;
- длительный взгляд вниз;
- взгляд в стороны или вверх;
- поворот/наклон головы;
- переключение на постороннее окно;
- запуск запрещённых программ;
- попытки использования запрещённых клавиш и сочетаний.

## Возможности

| Возможность | Описание |
|---|---|
| **Face tracking** | Отслеживание лица с помощью MediaPipe Face Landmarker |
| **Gaze tracking** | Анализ направления взгляда |
| **Head pose** | Определение поворота и наклона головы |
| **Phone detection** | Поиск смартфона в кадре с помощью YOLO |
| **Multi-person detection** | Обнаружение второго человека |
| **Camera protection** | Определение закрытой/перекрытой камеры |
| **Risk score** | Динамическая оценка вероятности списывания |
| **Window Guard** | Контроль активного окна |
| **Process Guard** | Поиск запрещённых программ |
| **Keyboard Guard** | Блокировка выбранных клавиш и hotkey |
| **Voice alerts** | Звуковые и голосовые предупреждения |
| **Event log** | Журнал событий в формате JSONL |
| **Evidence frames** | Сохранение кадров при обнаружении нарушений |
| **Final report** | Итоговый отчёт с графиком и статистикой |
| **i18n** | Русский, казахский и английский интерфейс |
| **Calibration** | Первичная калибровка положения головы и взгляда |

## Как это работает

Общий pipeline выглядит примерно так:

```text
Webcam
   │
   ├── YOLO ──────────────► Smartphone / Person detection
   │
   └── MediaPipe ─────────► Face / Gaze / Head pose
              │
              ▼
        Signal processing
              │
              ├── Persistence filter
              ├── Calibration
              ├── Rate analysis
              └── Event detection
              │
              ▼
          Risk Model
              │
              ▼
      Cheating probability
              │
       ┌──────┴──────┐
       ▼             ▼
   UI / Gauge     Event Log
                       │
                       ▼
                  Final Report
